🔀 2. Diretrizes de Roteamento Dinâmico (Router Guard)

  • Fluxo da Conta Premium: No primeiro login (onde acesso === 1), o roteamento redireciona compulsoriamente para o módulo de Elaborar Persona (Sliders MEVA). Nos acessos recorrentes, o redirecionamento pula o onboarding e o envia direto ao Construtor de Prompt (Tela 2). O botão de redefinir persona fica sempre aberto no menu lateral.
  • Fluxo da Conta Free: Ignora completamente o onboarding arquetípico e direciona o usuário imediatamente para o KS Studio (Tela 3) para criação e simulação manual do storyboard. O menu lateral de Personas fica bloqueado.
